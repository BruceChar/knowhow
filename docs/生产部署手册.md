# knowhow 生产部署手册

> 面向中小外贸企业自建知识库的正式部署指南。覆盖安全基线、常驻运行、HTTPS、备份恢复、升级与排障。
> 配套文件：`scripts/dev_server.sh`、`scripts/backup.sh`、`scripts/com.knowhow.server.plist`、`.env.example`。

## 1. 部署拓扑

```
[手机/同事电脑] ──局域网──> [Mac/服务器:8000  knowhow 服务]
                                    │
[外部网络] ──Cloudflare Tunnel / frp──┤
                                    │
                              [PostgreSQL 容器 rag_db:5433]
                              [本地 embedding 模型 bge-m3]
```

- 全部数据（知识库/会话/评测/审计）在本地 PostgreSQL，不出内网
- 模型本地加载，无需外部 API（LLM 可配置 API 或本地，见 docs/embedding选型对比.md）
- 单机单实例部署即可覆盖中小团队（<50 用户）

## 2. 安全基线（上线前逐项确认）

| 项 | 要求 | 落实方式 |
|---|---|---|
| 数据库密码 | 禁用开发密码 `rag_dev_2026` | `RAG_DSN` 环境变量换强密码；同步修改 docker compose 与容器 |
| 会话密钥 | 随机 32+ 字节 | `KNOWHOW_SECRET=$(openssl rand -base64 32)` 写入 .env |
| 登录密码 | 全部账号修改 | 生产模式 `KNOWHOW_PROD=1` 下种子密码随机生成并强制首次登录改密；或注入 `SEED_PASSWORDS=admin=强密码,editor=强密码`（默认仅两个账户 admin/admin、editor/editor） |
| 登录爆破 | 自动锁定 | 内置：连续 5 次失败锁 10 分钟（可配 `LOGIN_MAX_ATTEMPTS`/`LOGIN_LOCK_MINUTES`） |
| 会话安全 | httpOnly Cookie | 已实现：HttpOnly + SameSite=Lax；前端无 token 可窃 |
| HTTPS | 公网必须 | Cloudflare Tunnel 自带；frp 用 Caddy/Nginx 反代（见 §5） |
| 上传 | 类型+大小限制 | 已实现：白名单扩展名 + `MAX_UPLOAD_MB`（默认 50） |
| 防火墙 | 最小暴露 | 局域网只开 8000；数据库 5433 仅限本机回环 |

**生产首次启动：**

```bash
cp .env.example .env
# 编辑 .env：RAG_DSN / KNOWHOW_SECRET / KNOWHOW_PROD=1 / SEED_PASSWORDS=admin=强密码,editor=强密码
scripts/dev_server.sh   # 启动；若 SEED_PASSWORDS 未注入，随机密码打印一次请立即保存
```

## 3. 常驻运行

### macOS（launchd，推荐本机部署）

```bash
cp scripts/com.knowhow.server.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.knowhow.server.plist
# 查看状态
launchctl print gui/$(id -u)/com.knowhow.server
# 日志
tail -f /tmp/knowhow.err.log
# 停/启
launchctl unload ~/Library/LaunchAgents/com.knowhow.server.plist
launchctl load ~/Library/LaunchAgents/com.knowhow.server.plist
```

要点：plist 已配置 `KeepAlive`（崩溃自动拉起）+ `RunAtLoad`（开机自启）+ `HF_HUB_OFFLINE=1`。

### Linux 服务器（systemd 示例）

```ini
# /etc/systemd/system/knowhow.service
[Unit]
Description=knowhow admin api
After=network.target docker.service

[Service]
WorkingDirectory=/opt/knowhow
Environment=HF_HUB_OFFLINE=1
EnvironmentFile=/opt/knowhow/.env
ExecStart=/opt/knowhow/.venv/bin/uv run uvicorn src.api.admin_api:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

## 4. 备份与恢复

**每日备份（cron / launchd）：**

```bash
# crontab -e
0 2 * * * /Users/bruce/python/knowhow/scripts/backup.sh 14
```

**恢复演练（重要——未演练过的备份等于没有备份）：**

```bash
# 1. 找最新备份
ls -t data/backups/knowhow_*.dump.gz | head -1
# 2. 解压并用 pg_restore 恢复到临时库
gunzip -c data/backups/knowhow_20261023_195347.dump.gz > /tmp/kh.dump
docker exec -i rag_db pg_restore -U rag -d rag --clean --if-exists < /tmp/kh.dump
# 3. 验证：SKU 数、FAQ 数、用户数应恢复
docker exec rag_db psql -U rag -d rag -t -A -c "SELECT count(*) FROM faq;"
```

## 5. 公网 HTTPS

### Cloudflare Tunnel（自动 HTTPS，推荐）

```bash
cloudflared tunnel --url http://localhost:8000   # 临时域名
# 正式：cloudflared tunnel create knowhow + 绑定域名（见 docs/局域网部署与内网穿透.md）
```

### frp + Caddy（自建 VPS）

```nginx
# VPS 上 Caddyfile
kb.example.com {
    reverse_proxy 127.0.0.1:8000   # frps 把远程 8000 转发到本机
}
```
Caddy 自动签发免费证书；frps 配置见 `docs/局域网部署与内网穿透.md` 方案 B。

## 6. 监控

- **探活**：`curl http://localhost:8000/health` → `{"status":"ok","database":"ok","embedding":"ready",...}`
  - 状态 degraded = 数据库连不上；embedding cold = 模型未加载（首次访问会触发）
- **建议告警项**（可用 UptimeRobot/本地 cron 脚本）：
  - /health 非 ok 持续 3 分钟
  - 备份文件 48h 未更新
  - 日志出现 `ERROR`（登录爆破、评测失败）

## 7. 升级流程（版本迭代）

```bash
cd /Users/bruce/python/knowhow
git pull                  # 或拷入新版本代码
./scripts/backup.sh       # 先备份
docker exec -i rag_db psql -U rag -d rag < db/migration_v2.sql   # 应用新迁移（幂等）
launchctl kickstart -k gui/$(id -u)/com.knowhow.server           # 重启服务
curl http://localhost:8000/health                                # 验证
```

## 8. 排障速查

| 现象 | 原因与处理 |
|---|---|
| 启动卡几分钟 | 缺 `HF_HUB_OFFLINE=1`，模型反复连 huggingface.co → 加上重启 |
| 端口被占 | `pkill -f "uvicorn src.api.admin_api"` 后重启；勿用 9888 等历史调试端口 |
| 登录提示"失败次数过多" | 内存限流，重启服务即清；或等 10 分钟 |
| 数据库连不上 | 检查容器 `docker ps`（rag_db）；宿主机用 5433，容器内用 db:5432 |
| 忘了管理员密码 | `uv run python -c "import src.auth.auth as a; a.set_password(<system_account.id>,'新密码')"`（先查 id：`SELECT id FROM system_account WHERE username='admin'`） |
| 页面 401 循环 | Cookie 过期（24h）；重新登录即可 |
