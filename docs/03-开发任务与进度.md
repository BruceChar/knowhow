隔离验收：

```text
业务员看到：公司级知识 + 当前团队知识 + 自己的私有知识
业务员看不到：老板私有知识 + 其他团队知识
业务员访问角色管理/发布接口：403
调整业务员团队后：旧的团队知识立即不可见
```

## 2026-10-31：P1 完成

### 导入

- 支持 CSV、TXT、Markdown 文件。
- CSV 自动识别问题、答案、标题、说话人和消息列。
- 企业微信、WhatsApp、邮件等聊天导出可识别“客户/业务员”对话配对。
- 支持 `Q/A` 段落和 `---` 分隔。
- 预览阶段标记可导入、重复、错误行，并记录批次和 SHA-256。
- 执行导入后只生成待审核知识草稿。

### 知识治理

- 知识负责人可选择和保存。
- 知识有效期可选择，老板看板显示 14 天内到期知识。
- 新建知识时检测相同问题/标题和相同答案；不同答案返回相似知识提示。
- 上传文件批次、重复行和错误行可回看。

### 新人训练

- 训练题从当前用户可见的已发布 FAQ 随机生成。
- 作答后按关键业务信息覆盖率评分。
- 记录每次训练结果、参考答复、缺少要点和准备度。
- 老板看板纳入训练平均分。

### 混合检索

- 使用本地 `BAAI/bge-m3` 生成 1024 维 embedding。
- 知识发布时写入 pgvector，并记录模型名和更新时间。
- HNSW 索引检索向量 Top 候选。
- Jieba 关键词召回作为第二路。
- 加权 RRF 融合两路结果。
- 无 embedding 时自动降级为关键词检索。

真实验收：

```text
CSV 导入 2 条 → 生成 2 条草稿 → 发布并写入 2 个 bge-m3 向量
英文问题 “What leash options do you offer?”
→ 中文“牵引绳分类”知识命中
→ retrieval.mode = hybrid，lexical_candidates = 0
训练题 2 条 → 作答 100 分 → 准备度 100
```

当前限制：

- 模型首次加载约 30 秒；发布 embedding 仍为同步操作，后续应改后台任务。
- “企业微信/WhatsApp/邮件”当前导入的是导出文件，不是官方 API 实时连接。
- 训练评分衡量关键信息覆盖，不替代负责人对表达质量的复核。
