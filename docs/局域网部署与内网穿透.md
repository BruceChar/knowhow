# 局域网部署与内网穿透

> 目标：让知识库管理后台（FastAPI + PG + 本地向量库）从"只能本机访问"变成"局域网可访问、外部网络可访问"，并配合账户登录保证安全。

## 一、现状与问题

| 项目 | 现状 | 说明 |
|---|---|---|
| 服务绑定 | `127.0.0.1` | 只有本机能访问 |
| 认证 | 已上线（v3） | 账号密码登录 + Bearer token 会话，未登录看不到任何管理功能 |
| 数据库 | Docker 容器 `rag_db`（5433） | 仅本机 |
| 模型 | bge-m3 本地（data/models） | 本地加载，无需外网 |

## 二、第一层：局域网访问（0.0.0.0 绑定）

**启动脚本：**

```bash
scripts/dev_server.sh          # 默认端口 8000
scripts/dev_server.sh 9000     # 指定端口
```

脚本会探测本机局域网 IP（如 `192.168.1.20`），打印访问地址：

- 本机：`http://localhost:8000/admin`
- 局域网其他设备（手机/同事电脑）：`http://192.168.1.20:8000/admin`

**要点：**
1. 同一 WiFi/局域网即可访问，无需公网。
2. macOS 首次可能弹防火墙确认，允许即可。
3. 安全：局域网内所有设备都看得到登录页——**必须登录才能进入**，请尽快修改默认密码。

## 三、第二层：内网穿透（外部网络访问）

场景：出差在外想访问公司/家里的服务，或让不在同一局域网的同事访问。原理：把本地端口映射到一个公网可达的地址。

### 方案对比

| 方案 | 成本 | 稳定性 | 适合场景 | 缺点 |
|---|---|---|---|---|
| **Cloudflare Tunnel** | 免费（自带域名免费，绑定自有域名免费） | 好，CF 全球节点 | 演示、中小团队、无公网 IP | 域名需实名，国内访问速度一般 |
| **frp（自建）** | 需要一台有公网 IP 的 VPS（~¥50/月） | 最好，可控 | 生产环境、长期使用 | 要运维 VPS |
| **ngrok** | 免费版有域名随机/限速 | 一般 | 临时演示 | 免费版不稳定 |
| 花生壳等内网穿透服务 | 免费版限速 | 一般 | 个人使用 | 免费体验差，付费贵 |

**推荐：** 演示/起步用 Cloudflare Tunnel；正式投入用 frp 自建。

### 方案 A：Cloudflare Tunnel（免费，推荐起步）

```bash
# 1. 安装 cloudflared（macOS）
brew install cloudflared

# 2. 无需账号的快速隧道（临时随机域名，适合演示）
cloudflared tunnel --url http://localhost:8000
# 输出形如 https://xxx-random.trycloudflare.com —— 直接可访问，Ctrl+C 即停

# 3. 正式绑定自有域名（需要 Cloudflare 账号 + 域名）
#    登录 https://one.dash.cloudflare.com 创建隧道，然后：
cloudflared tunnel create knowhow
cloudflared tunnel route dns knowhow kb.example.com
# 配置文件 ~/.cloudflared/config.yml
#   tunnel: <TUNNEL_ID>
#   credentials-file: /Users/xxx/.cloudflared/<TUNNEL_ID>.json
#   ingress:
#     - hostname: kb.example.com
#       service: http://localhost:8000
#     - service: http_status:404
cloudflared tunnel run knowhow
# 之后用 launchd/pm2 常驻
```

### 方案 B：frp 自建（生产推荐）

前提：一台有公网 IP 的 VPS（阿里云/腾讯云轻量即可，~¥50/月）。

**VPS 端（frps）：**

```bash
# 下载 frp 最新版（https://github.com/fatedier/frp/releases），解压
# frps.toml：
#   bindPort = 7000
./frps -c frps.toml
```

**本机端（frpc）：**

```bash
# frpc.toml：
#   serverAddr = "你的VPS公网IP"
#   serverPort = 7000
#   [[proxies]]
#   name = "knowhow-web"
#   type = "tcp"
#   localIP = "127.0.0.1"
#   localPort = 8000
#   remotePort = 8000
./frpc -c frpc.toml
```

访问：`http://你的VPS公网IP:8000/admin`（需在 VPS 安全组放行 7000/8000 端口）。

生产加固建议：
- frps 加 `auth.token` 防止被蹭；
- VPS 上反代一层 HTTPS（Caddy/Nginx + 免费证书），浏览器访问 `https://...`。

## 四、账户登录与安全清单（必读）

系统已内置账户登录（v3）：账号密码登录、Bearer token 会话、24h 过期、登出销毁。

**上线前必做：**

- [ ] 修改 2 个默认账户密码（`admin/admin`、`editor/editor`）—— 任何人能登录意味着所有知识库数据暴露；在系统管理→账户管理页直接重置
- [ ] 修改数据库密码：`db/migration_v2.sql` 中 `rag_dev_2026` 为开发密码
- [ ] 局域网/穿透暴露后，检查防火墙只放行必要端口
- [ ] 公网访问建议套 HTTPS（Cloudflare Tunnel 自动 HTTPS；frp 需自己配）
- [ ] 会话过期时间 `SESSION_TTL_HOURS`（src/auth/auth.py）按需调整

**账号权限矩阵（已有）：**

| 角色 | 数据 | 审核/评测 | 入录 | 用户管理 |
|---|---|---|---|---|
| agent（客服） | public+internal 检索 | - | - | - |
| editor（业务员） | 全部 | - | 编辑/打标/上传 | - |
| reviewer（审核员） | 全部 | 通过/驳回/评测/审计 | 编辑 | - |
| admin（管理员） | 全部 | 全部 | 全部 | 创建用户/改角色 |

## 五、常驻运行（可选）

```bash
# 本机常驻：用 nohup 或 pm2
nohup HF_HUB_OFFLINE=1 uv run uvicorn src.api.admin_api:app --host 0.0.0.0 --port 8000 > /tmp/knowhow.log 2>&1 &

# pm2（推荐，自带重启/日志）
npm i -g pm2
pm2 start "HF_HUB_OFFLINE=1 uv run uvicorn src.api.admin_api:app --host 0.0.0.0 --port 8000" --name knowhow
pm2 save && pm2 startup
```

## 六、已知坑（运维备忘）

- 端口被占：`pkill -f "uvicorn src.api.admin_api"` 后再启；9888 等历史测试端口勿用
- 模型冷加载：服务必须带 `HF_HUB_OFFLINE=1`，否则反复连 huggingface.co 卡数分钟
- 数据库端口 5433（本机 5432 被系统 PG 占用），容器内用 `db:5432`
